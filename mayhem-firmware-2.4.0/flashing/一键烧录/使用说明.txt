PortaPack H2 / HackRF 固件合集 + 一键烧录
整理日期：2026-11-07（含全部已搜集固件）
==========================================================

一、怎么用（三步）

  1. 双击  一键烧录.bat
  2. 输入序号（例如 1 = 卖家 mod2）
  3. 确认设备已进 HackRF 模式后，输入 Y 开始烧录

  设备进 HackRF 模式的方法：
    开机 -> 主菜单里选 "HackRF" -> 屏幕变黑或只显示一行字，属正常，
    这时电脑才能识别到设备（VID_1D50）。

五、三个必须知道的坑

  1. 烧录会先整片擦除再写入
     hackrf_spiflash -w 的动作是 Erase -> Write。中途 USB 断开，
     原固件就永久没了，找不回来。
     => 设备上有不想丢的固件，先按主菜单 [B] 备份（只读，不改设备）。

  2. hackrf_info 显示的版本号 ≠ 界面版本号
     每个固件内部有两条版本串：界面版本 + HackRF 基座版本。
     例如烧 1 号 mod2，hackrf_info 会显示 local-de927bd，
     而界面版本其实是 be45cf6 —— 这是正常的，不是烧错了。
     判断烧的是哪个文件，靠界面版本串（0x058E00 附近）。

  3. 烧完黑屏
     H2 有不同型号的 LCD 驱动。断电后按住 5 个按键中的任意一个再上电，
     逐个按键试，屏幕就会亮。


六、USB 链路不稳怎么办

  本机曾多次出现 Pipe error (-1000)（大块传输时 USB 断开），特征是：
  hackrf_info 能正常识别，但 spiflash -r 一读就断。

  处理顺序：
    1. 换 USB 数据线（很多线只能充电）
    2. 直插主机后置 USB 口，别经过 hub / 前置面板 / 扩展坞
    3. 换一台电脑交叉验证

  临时验证手段（不受大块传输影响）：
    bin\hackrf_spiflash.exe -a 0x058E00 -l 0x200 -r check.bin
    读 512 字节小区域，可与固件文件对应偏移逐字节比对。

八、手动命令（不想用脚本时）

  在工作目录 一键烧录 下执行：

    查设备:      bin\hackrf_info.exe
    烧固件:      bin\hackrf_spiflash.exe -R -w firmware\1_mod2_seller.bin
    读备份:      bin\hackrf_spiflash.exe -r backup_flash.bin
    读小块:      bin\hackrf_spiflash.exe -a 0x058E00 -l 0x200 -r check.bin
    救砖:        bin\dfu-util-static.exe -d 1fc9:000c -D firmware\hackrf_usb_recovery.dfu

  参数说明：
    -R  操作完成后复位设备
    -w  写入（会先擦除整片）
    -r  读出整片
    -a  起始地址    -l  读取长度（配合 -r 做小块读）
