- 固件命名：1_mod2_seller(local-be45cf6) / 2_mod_seller(de927bd) / 3_havoc_seller(127a798) / 4_spk_2019 / 5_havoc_master_20200420 / 6_havoc_20180612 / 7_mayhem_v1.0.0 / 8_mayhem_v2.4.0 / hackrf_usb_recovery.dfu
- 脚本功能：菜单选固件 → 检测设备 → Y 确认 → 烧录 → 显示设备信息；[B] 整片读备份（只读）；[D] DFU 救砖
- 关键技术点：bat 必须 GBK 编码 + chcp 936，否则 cmd 内中文乱码；Write 工具只能写 UTF-8，需 python 转 GBK + CRLF 换行
